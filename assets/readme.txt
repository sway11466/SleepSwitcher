====================================================
  SleepSwitcher — ユーザーガイド
====================================================

■ 概要
  Windows 11 のスリープ・休止状態を自動制御するシステムトレイ常駐アプリです。
  曜日・時間帯ごとのスケジュールでスリープを自動的に有効／無効にできます。

■ 動作環境
  Windows 11

====================================================
  インストール
====================================================

【zip 版】
  1. SleepSwitcher_v1.1.0.zip を任意のフォルダに解凍
  2. 解凍してできた 3 つのファイル（exe／csv／readme）を同じフォルダに置いたまま
     SleepSwitcher.exe をダブルクリックで起動

  ＜スタートアップ登録（自動起動したい場合）＞
  1. Win + R キーで「ファイル名を指定して実行」を開く
  2. shell:startup と入力して OK
  3. 開いたフォルダに SleepSwitcher.exe のショートカットを置く

【インストーラー版】
  1. SleepSwitcher_Setup.exe をダブルクリック
  2. ウィザードに従ってインストール
  ※ インストール時にスタートアップ登録を選択できます

====================================================
  使い方
====================================================

■ トレイアイコン
  起動するとシステムトレイにアイコンが表示されます。

    緑（Z）    : スリープ有効（スリープする）
    グレー（Z） : スリープ無効（スリープしない）

  右クリックメニューからスリープの有効／無効を即時切り替えできます。

■ 設定画面
  トレイアイコンを右クリック →「設定...」で設定画面を開きます。

  ＜スリープ設定＞
  ・有効／無効の切り替え
  ・スリープ・休止状態のタイムアウト時間を設定
    （電源接続時・バッテリー時それぞれ設定可能）
  ・0 = 無効（スリープしない）

  ＜スケジュール＞
  ・曜日と祝日（祝行）ごとにスリープを無効にする時間帯を 30 分単位で設定
  ・祝日に該当する日は曜日設定ではなく「祝」行の設定が適用されます
  ・緑のセル  : スリープ ON（スリープする）
  ・グレーのセル: スリープ OFF（スリープしない）
  ・セルをクリック／ドラッグで切り替え
  ・今日の行ラベルは赤太字で強調され、現在時刻の位置に赤丸が表示されます

  設定後「適用」または「適用して閉じる」で保存されます。

====================================================
  祝日について
====================================================

  ・祝日判定は同梱の syukujitsu.csv（内閣府データ、1955〜2027 年）で行います。
  ・以下の優先順で読み込みます。
      1. %APPDATA%\SleepSwitcher\syukujitsu.csv（ユーザ上書き用）
      2. SleepSwitcher.exe と同じフォルダの syukujitsu.csv

  ・独自の祝日を追加したい場合は、設定画面の「使い方・注意事項」から
    「このCSV」「このフォルダ」リンクをクリックして編集・保存できます。

====================================================
  注意事項
====================================================

  ・アプリを終了するとスケジュール制御が止まります。
    常にトレイに常駐させてください。
  ・PC がスリープ状態に入ってしまった場合は、
    手動で復帰させる必要があります。
  ・設定は以下の場所に保存されます。
    %APPDATA%\SleepSwitcher\config.json
