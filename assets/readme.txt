====================================================
  SleepSwitcher — ユーザーガイド
====================================================

■ 概要
  Windows 11 のスリープ・休止状態を自動制御するシステムトレイ常駐アプリです。
  曜日・時間帯ごとのスケジュールでスリープを自動的に有効／無効にできます。

■ 動作環境
  Windows 11

====================================================
  インストール
====================================================

【exe 版】
  1. SleepSwitcher.exe を好きな場所に置く
  2. ダブルクリックで起動

  ＜スタートアップ登録（自動起動したい場合）＞
  1. Win + R キーで「ファイル名を指定して実行」を開く
  2. shell:startup と入力して OK
  3. 開いたフォルダに SleepSwitcher.exe のショートカットを置く

【インストーラー版】
  1. SleepSwitcher_Setup.exe をダブルクリック
  2. ウィザードに従ってインストール
  ※ インストール時にスタートアップ登録を選択できます

====================================================
  使い方
====================================================

■ トレイアイコン
  起動するとシステムトレイにアイコンが表示されます。

    緑（Z）    : スリープ有効（スリープする）
    グレー（Z） : スリープ無効（スリープしない）

  右クリックメニューからスリープの有効／無効を即時切り替えできます。

■ 設定画面
  トレイアイコンを右クリック →「設定...」で設定画面を開きます。

  ＜スリープ設定＞
  ・有効／無効の切り替え
  ・スリープ・休止状態のタイムアウト時間を設定
    （電源接続時・バッテリー時それぞれ設定可能）
  ・0 = 無効（スリープしない）

  ＜スケジュール＞
  ・曜日ごとにスリープを無効にする時間帯を 30 分単位で設定
  ・緑のセル  : スリープ ON（スリープする）
  ・グレーのセル: スリープ OFF（スリープしない）
  ・セルをクリック／ドラッグで切り替え

  設定後「適用」または「適用して閉じる」で保存されます。

====================================================
  注意事項
====================================================

  ・アプリを終了するとスケジュール制御が止まります。
    常にトレイに常駐させてください。
  ・PC がスリープ状態に入ってしまった場合は、
    手動で復帰させる必要があります。
  ・設定は以下の場所に保存されます。
    %APPDATA%\SleepSwitcher\config.json
