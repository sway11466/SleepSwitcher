# spec.md — SleepSwitcher 機能仕様

## 機能要件

| # | 機能 | 詳細 |
|---|------|------|
| F1 | スリープ時間設定 | モニタースリープまでの時間を分単位で設定 |
| F2 | スリープ無効化 | スリープを OFF（常時稼働） |
| F3 | スリープ有効化 | スリープを ON（F1 の設定時間後に自動スリープ） |
| F4 | スケジュール機能 | 曜日単位で異なるルールを自動適用 |
| F5 | 常駐アプリ | システムトレイに常駐し、トレイアイコンから操作 |
| F6 | 設定永続化 | 設定を JSON ファイルに保存・起動時に復元 |

## スケジュール仕様

### 曜日単位ルール

各曜日グループに「スリープ OFF にする時間帯（off_hours）」を設定する。

```
平日（月〜金）デフォルト:
  09:00 〜 18:00 → スリープ OFF
  18:00 〜 09:00 → スリープ ON

休日（土日）デフォルト:
  終日 → スリープ ON（off_hours なし）
```

### スケジュール判定ロジック

```python
def should_sleep_be_disabled_now(config, current_datetime) -> bool:
    # 将来: 祝日判定
    # 曜日ルールを走査して off_hours 内なら True を返す
    # マッチするルールがなければ False（スリープ ON）
```

- 1分ごとに定期チェックして自動適用（A案採用）
- 手動操作はスケジュールを上書きする（次のスケジュール適用タイミングまで有効）

### 将来拡張：祝日対応（フェーズ 3）

```json
"holidays": [
  {"date": "2025-01-01", "name": "元日", "sleep_off": false}
]
```

## 設定ファイル仕様（config.json）

```json
{
  "sleep_time_minutes": 15,
  "schedule": {
    "enabled": true,
    "rules": [
      {
        "weekday": "mon-fri",
        "description": "平日",
        "off_hours": {
          "start": "09:00",
          "end": "18:00"
        }
      },
      {
        "weekday": "sat-sun",
        "description": "休日",
        "off_hours": null
      }
    ],
    "holidays": []
  }
}
```

### フィールド定義

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `sleep_time_minutes` | int | スリープまでの分数（1〜480） |
| `schedule.enabled` | bool | スケジュール機能の有効/無効 |
| `schedule.rules[].weekday` | string | `"mon-fri"` / `"sat-sun"` / `"mon"` 等 |
| `schedule.rules[].off_hours` | object\|null | スリープ OFF にする時間帯。null で終日 ON |
| `schedule.holidays` | array | 祝日リスト（フェーズ 3 用、初版は空配列） |

## UI 仕様

### システムトレイアイコン

- 状態に応じてアイコンを切り替え
  - スリープ有効：通常アイコン
  - スリープ無効：強調アイコン（赤系）

### トレイメニュー

```
[現在の状態表示]（クリック不可、ラベル）
─────────────────────
スリープ有効化
スリープ無効化
─────────────────────
スリープ時間設定...
スケジュール設定...
─────────────────────
終了
```

### スリープ時間設定ダイアログ

- スピンボックスで分数を入力（1〜480分）
- OK / キャンセルボタン

### スケジュール設定ダイアログ（フェーズ 2）

- スケジュール有効/無効のチェックボックス
- 曜日グループごとに開始・終了時刻を入力
- 保存ボタン

## 非機能要件

- 管理者権限不要で動作
- 起動時にスケジュール状態を自動適用
- CPU 負荷を最小限に（1分ごとのポーリング）
- Windows 11 専用
