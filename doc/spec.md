# spec.md — SleepSwitcher 機能仕様

## 機能要件

| # | 機能 | 詳細 |
|---|------|------|
| F1 | スリープ時間設定 | デバイスのスリープ・休止状態までの時間を分単位で設定（電源接続・バッテリーそれぞれ） |
| F2 | スリープ無効化 | スリープ・休止状態を OFF（常時稼働） |
| F3 | スリープ有効化 | スリープ・休止状態を ON（F1 の設定時間後に自動移行） |
| F4 | スケジュール機能 | 曜日・時間帯単位でスリープの有効/無効を自動切り替え |
| F5 | 常駐アプリ | システムトレイに常駐し、トレイアイコンから操作 |
| F6 | Windows 設定の読み書き | 起動時に Windows の現在値を読み込み、変更時は Windows に直接書き込む |
| F7 | 設定の永続化 | タイムアウト値・スケジュールルールを JSON ファイルに保存・起動時に復元 |

## スケジュール仕様

### 曜日ごとの設定

月〜日それぞれに「スリープ OFF にする時間帯」を複数設定できる。

- 時間帯は `from`〜`to` の配列で表現
- 空配列 = 終日スリープ ON
- UI 上は 30分単位のグリッドで操作
- `config.json` を直接編集する場合は分単位で記述可能

### スケジュール判定ロジック

```python
def should_sleep_be_disabled(days_config, current_datetime) -> bool:
    # 現在の曜日・時刻が、いずれかの off_periods 内に含まれるなら True
```

- 1分ごとに定期チェックして自動適用
- スケジュールと手動操作は**優先度なしで上書き関係**（後勝ち）
- スケジュール変更保存時に `apply_schedule(now)` を実行し、現在時刻で即時評価・適用

### 将来拡張：祝日対応（フェーズ 3）

```json
"holidays": [
  {"date": "2025-01-01", "name": "元日", "sleep_off": false}
]
```

## Windows 電源設定の仕様

### 管理対象の設定値

| 設定 | powercfg パラメータ | 説明 |
|------|-------------------|------|
| デバイスをスリープ（電源接続） | `standby-timeout-ac` | 0 = 無効 |
| デバイスをスリープ（バッテリー） | `standby-timeout-dc` | 0 = 無効 |
| 休止状態（電源接続） | `hibernate-timeout-ac` | 0 = 無効 |
| 休止状態（バッテリー） | `hibernate-timeout-dc` | 0 = 無効 |

### 読み書きの方針

- **起動時**：`powercfg /query` で Windows の現在値をすべて読み込む
- **変更時**：`powercfg /change` で Windows に直接書き込む
- **タイムアウト値は `config.json` にも保存**し、再起動後も復元できるようにする

### スリープ無効化・有効化の動作

- **無効化**：4つのタイムアウト値をすべて 0 に設定。数値は `config.json` に保持
- **有効化**：`config.json` の値を Windows に書き込む

## 設定ファイル仕様（config.json）

```json
{
  "timeouts": {
    "standby_ac":   15,
    "standby_dc":   10,
    "hibernate_ac": 180,
    "hibernate_dc": 180
  },
  "schedule": {
    "days": {
      "mon": [{"from": "09:00", "to": "18:00"}],
      "tue": [{"from": "09:00", "to": "18:00"}],
      "wed": [{"from": "09:00", "to": "18:00"}],
      "thu": [{"from": "09:00", "to": "18:00"}],
      "fri": [{"from": "09:00", "to": "18:00"}],
      "sat": [],
      "sun": []
    },
    "holidays": []
  }
}
```

### フィールド定義

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `timeouts.standby_ac` | int | スリープまでの分数（電源接続）。0 = 無効 |
| `timeouts.standby_dc` | int | スリープまでの分数（バッテリー）。0 = 無効 |
| `timeouts.hibernate_ac` | int | 休止状態までの分数（電源接続）。0 = 無効 |
| `timeouts.hibernate_dc` | int | 休止状態までの分数（バッテリー）。0 = 無効 |
| `schedule.days.{曜日}` | array | スリープ OFF にする時間帯のリスト |
| `schedule.days.{曜日}[].from` | string | OFF 開始時刻（`"HH:MM"` 形式、分単位まで有効） |
| `schedule.days.{曜日}[].to` | string | OFF 終了時刻（`"HH:MM"` 形式、分単位まで有効） |
| `schedule.holidays` | array | 祝日リスト（フェーズ 3 用、初版は空配列） |

## UI 仕様

### システムトレイアイコン

- 状態に応じてアイコンを切り替え
  - スリープ有効：緑系アイコン
  - スリープ無効：赤系アイコン

### トレイメニュー

```
● スリープ有効化
○ スリープ無効化
─────────────────────
  設定...
─────────────────────
  終了
```

### 設定画面

```
┌─────────────────────────────────────────────────────────┐
│  【スリープ設定】  ● 有効  ○ 無効                        │
│   ※ スケジュールにより自動制御中（スケジュール動作時）   │
│   スリープ（電源接続）   [  15 ] 分                      │
│   スリープ（バッテリー） [  10 ] 分                      │
│   休止状態（電源接続）   [ 180 ] 分                      │
│   休止状態（バッテリー） [ 180 ] 分                      │
├─────────────────────────────────────────────────────────┤
│  【スケジュール】                                         │
│      0  1  2  3 ... 23                                  │
│  月 [■][■][  ] ...                                      │
│  火 [■][■][  ] ...                                      │
│  水 [■][■][  ] ...                                      │
│  木 [■][■][  ] ...                                      │
│  金 [■][■][  ] ...                                      │
│  土 [  ][  ][  ] ...                                    │
│  日 [  ][  ][  ] ...                                    │
├─────────────────────────────────────────────────────────┤
│                          [ 変更 ]  [ 閉じる ]            │
└─────────────────────────────────────────────────────────┘
```

- スリープ設定が無効の場合、タイムアウト値の入力欄はグレーアウト（値は保持）
- スケジュール動作中は「スケジュールにより自動制御中」を表示
- スケジュールのグリッドは 30分単位でトグル操作
- 「変更」ボタン押下で Windows への書き込みとスケジュール即時評価を実行

## 非機能要件

- 管理者権限不要で動作
- 起動時にスケジュール状態を自動適用
- CPU 負荷を最小限に（1分ごとのポーリング）
- Windows 11 専用
